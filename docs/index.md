# Gateway guides

Use the gateway your team already runs, or host one for your team.

- **[Connect to my team](mac-install.md)** — install the Mac app, sign in and choose a tool.
- **[Set up a gateway](deployment.md)** — start a private server and sign in as its first administrator.

## Working with tools

[Connect your coding agent](agent-configuration.md) once to use your enabled tools. To try the whole flow with a small example, follow the [echo walkthrough](quickstart.md#try-an-echo-tool).

## Managing a team

[Give someone access](admin-ui.md), [add an MCP server](integrations.md) or [configure OAuth](oauth.md). For permissions and offline behavior, see [access settings](configuration.md) and [security](security.md).

## Help and reference

Check [troubleshooting](troubleshooting.md) when a tool is missing or a connection fails. See [supported platforms](compatibility.md), [archive checksums](checksums.md) and [backup and recovery](operations.md) for deployment details.
