# Product roadmap

## Available today

Teams can host a gateway, assign tools to people or groups, and control which tools a coding agent can use. Developers sign in on their Mac, choose which assigned tools to enable and connect their agent once.

See [supported platforms](compatibility.md), [how access works](architecture.md) and [Get started](quickstart.md).

## Directions under consideration

- Signed and notarized Mac downloads.
- Support for additional endpoint platforms, coding agents and OAuth providers.
- Enterprise single sign-on and additional deployment options.

These are possibilities for future releases. Use the compatibility guide when deciding what to deploy today.
